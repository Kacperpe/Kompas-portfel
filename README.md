# Kompas Portfela

Tracker portfela inwestycyjnego w jednym pliku: transakcje, pozycje, gotówka per waluta i konto, alokacja docelowa z pasmem odchyleń i wskazówki rebalansingu.

- Import z CSV / XLS / XLSX / ODS albo wklejki z Excela, z automatycznym dopasowaniem kolumn
- Eksport do CSV
- Dane w `localStorage` przeglądarki (rób eksport jako kopię zapasową)

Statyczna strona, bez builda. Deploy: Vercel, katalog główny.
